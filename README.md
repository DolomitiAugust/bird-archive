# 鸟类档案馆

按真实摄影浏览鸟种，也可以按鸟名、学名或分类查阅全球名录。[打开档案馆](https://dolomitiaugust.github.io/bird-archive/)

图库每格保留一张照片和鸟名。打开档案可以查阅分类、辨识要点、资料出处和逐张授权。下载的照片放在 `photos/`，对应的物种和摄影资料保存在 `data/photos.json`。

## 本地运行

在仓库根目录运行以下命令，然后打开浏览器访问本机的 8000 端口。

```sh
python -m http.server 8000
```

## 照片与署名

每张照片沿用文件页注明的许可。详情页保留摄影者、原始文件页、许可链接和处理说明。站内只对图像等比例缩小并转为 WebP。总览按卡片尺寸裁切显示，详情保留完整画幅。尚无可核实实拍的物种保留文字档案。
